# DIGO Design Worlds v0.1

Additive, isolated concept preview at `/design-lab/index.html`, linked from the home page. Existing catalog, cart, checkout, database, and payment routes are unchanged.

## Implemented
Six defined brand directions plus an explicitly unapproved sixth-brand proposal. Twenty-one AI-authored concept records, seven illustrated scenes, eight manually researched reference records (snapshot 2026-11-05). Clickable SVG concepts and scene hotspots; brand filters; browser-local saves; JSON design-review, rendering-brief and run exports. Deterministic engine for provenance presence, scene tag matching and explicit missing manufacturing evidence. Nothing is sold or approved through this module.

## Not implemented
No live crawler, no cross-platform popularity ranking, no generative model API, no model image render backend, no authenticated approval service, no persistent server run database, no production Tech Packs, no validated DXF patterns, no actual samples or factory integrations. The workflow button does not rerun web searches or generate new designs. SVGs are illustrative rather than scaled technical flats; not all described details are drawn.

## Safe expansion
Move manufacturing approvals to a server-side evidence service with role separation and immutable revision identifiers before connecting commerce. Require original or licensed image assets. Keep social likes and denominator provenance null when unavailable. Add authorized platform metrics rather than bypassing access controls. Any renderer must preserve SKU geometry across scene and product images; a real sample remains required before customer-facing product promises.

## Verification
Pure Node tests passed for 21 unique styles, reference integrity, unknown popularity handling, explainable scene matches, client flags unable to authorize commerce, open proposal status, invalid style rejection, complete runs and unknown supplier data. Chromium interaction tests passed for filtering, dialogs, exports, scene selection, execution and 390px layout. Browser network navigation was blocked in the local environment; in-memory HTML and a test storage adapter were used, so real-origin persistence still requires live-site verification.
