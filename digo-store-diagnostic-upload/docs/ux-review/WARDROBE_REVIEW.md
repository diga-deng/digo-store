## 付款后自动入柜

沿用现有 Stripe 付款验证和订单写入路径。服务端确认 paid、DIGO 订单标识和模式匹配，且订单存储成功后，成功页才下发去除个人/付款/采购敏感字段的商品回执。

成功页自动保存当前设备的订单回执；衣柜启动时合并到原商品记录，按订单 ID 去重，不重建已有分组与搭配。真实付款归入 Purchased；定金标注预售；测试回执单独标注 Test purchase，不自动视为已拥有。

付款不等于收货。本轮没有接入收货状态与账户同步，也没有开放真实收款。若付款后未返回确认页，当前版本不会仅依赖 webhook 在另一设备自动恢复；完整恢复仍需账户与订单查询能力。
